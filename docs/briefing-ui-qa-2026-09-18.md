# 브리핑 시안 UI 점검 및 수정 계획

범위: 별도 HTML 시안. 기존 제품 코드나 Notion에 쓰지 않는다.

확인된 문제: 현재 스프린트의 바깥 label 안에 여러 label과 버튼이 중첩됨. 필터의 모든 input에 적용된 폭 100%·높이 42px가 체크박스에도 적용됨. 모든 label의 grid 스타일이 선택 행을 덮음. 목록이 필터 행 높이를 늘리며 다른 필터가 아래로 이동함. 삭제된 syncScopeInput 호출로 초기 실행 중단. 이전 시안과 실제 집계 스크립트가 중복 실행됨.

수정 순서: 시안 초기 실행을 재현하는 독립 DOM 대역 테스트 → 오래된 중복 스크립트 제거 → 현재 스프린트 하나에 실제 목록 통합 → 선택 행과 검색 스타일 분리 → 즉시 조회·검색·초기화 동작 검증.

시각 기준: 기존 시스템 글꼴·본문 15px 유지. 흰색 #fff, 본문 #202b3a, 보조 #596779, 경계 #dce1e7, 선택 #3354bd. 필터 상단 정렬. 데스크톱 목록은 필터 아래 떠 있는 패널, 좁은 화면은 한 열의 흐름 안에서 펼침. 선택 행은 체크박스 18px와 왼쪽 정렬된 이름, 최소 높이 44px. 선택 개수는 접힌 제목에 표시하고 선택 즉시 조회한다.

검증 기준: 첫 실행 오류 없음, 선택기 하나, 실제 스냅샷의 스프린트 목록·별칭 정규화, 검색 결과에서 바꿔도 다른 선택 유지, 빈 상태와 미선택 구분, 선택 즉시 KPI 갱신, 프로젝트·팀·담당자 실제 원문 필터 반영. 브라우저 정책 접근 실패 시 화면/모바일 직접 검증 통과를 주장하지 않는다.

## 결과

후속 변경 결과: 순서 제어, 저장 버튼·저장 상태·저장 이력·localStorage 읽기/쓰기를 제거했다. 스프린트 선택은 메모리 내 즉시 조회로 단일화했다. data/dashboard.json 스냅샷(2026-08-07)의 프로젝트 6개, 하위 업무 139개, 가이드 위반 child/parent ID, 현재 스프린트 준비 ID를 시안에 포함해 동일 원천으로 계산한다. 메인 준비 필요 기준은 현재 선택 스프린트의 시작 전 하위 업무 중 기한 초과 제외이며 단순 시작 전 총계와 다르다.

- 수정 전: 실제 시안의 두 스크립트를 격리된 DOM 대역에서 실행하자 syncScopeInput ReferenceError로 4개 시나리오 모두 실패했다. 문법 검사와 기존 제품의 245개 테스트는 이 시안의 실행을 검증하지 않았음.
- 수정 후: 시안 전용 8개 동작 검사 통과. 첫 로드의 5개 지표 렌더링, 실제 스프린트 목록, 스프린트60·61 KPI, 다중 선택 집계, 프로젝트 목록·현재 진행 요약, 팀 필터, 초기화를 포함한다.
- HTML 구조 검사: 중첩 label 없음, 중복 ID 없음, 현재 스프린트 선택기 1개.
- 제거: 구 시안의 가상 지표 렌더러와 중복 이벤트, 삭제된 함수 호출, 근거 없이 임의 지정한 담당자·팀 값.
- 데이터 제한: 원천은 2026-08-07 스냅샷이며 실시간 Notion 동기화가 아니다. 빌드·출시·Slack·회의 데이터는 이 시안에 연결하지 않았다. 실제 서비스 메인 브랜치에 넣기 전 최신 스냅샷으로 다시 확인해야 한다.
- 직접 화면 검증: localhost 탭 접근 시 관리 정책 확인 실패로 차단됨. 브라우저 보안 통제를 우회하지 않았고 데스크톱/모바일 픽셀 검증은 미완료다. DOM 대역 테스트는 레이아웃·실제 키보드 탭 순서·스크린리더 동작을 입증하지 않는다.
