# 업무현황 대시보드 가독성 개선

## 목적
대표와 프로젝트 책임자가 결정 요청, 분석상 위험, 미검토 후보, 관리 점검을 구분하고 필요한 업무 근거로 이동할 수 있게 한다. 의미와 최신성을 보존하는 정보 계층이 우선이며, 미적 장식만 바꾸지 않는다.

## 성공조건 및 검증
1. 기본 브리핑과 detail=setup 링크 모두 대표 결정/분석이 관리 상세보다 먼저 표시된다. DOM 순서 및 브라우저 확인.
2. 에이전트 주요 위험과 출처 attention 후보는 별도 영역이다. 후보가 5개 이상이어도 분석 위험이 사라지지 않는다. 회귀 테스트.
3. 결정 없음과 미분석/부분/오래된 분석을 구분한다. 실패를 오래됨으로 둔갑시키지 않는다. 수집/분석 시각은 한국 시간으로 표시한다. 고정 시각 테스트.
4. 에이전트 병목·다음 행동을 문자열 키워드로 삭제하지 않는다. 원문 의미 유지 회귀 테스트.
5. 1440px/768px/375px 및 320px 폭에서 브리핑 페이지 가로 넘침이 없고 긴 한국어 제목과 본문이 줄바꿈된다. 양 테마, 키보드 포커스, 메뉴·필터·상세 펼침 확인.
6. 기존 수집·판정·원격 쓰기·공유 계약을 유지한다. 전체 테스트와 빌드/구문 검사, 실제 데이터의 읽기 전용 로컬 미리보기 검증. 새 의존성 없음.

## 조사와 선택
- NN/g Progressive Disclosure: 기본 화면에는 주요 판단을, 보조 정보는 명확한 펼침으로 제공. https://www.nngroup.com/articles/progressive-disclosure/
- GOV.UK Task list: 제목/설명/상태를 분리하고, 기본 상태의 시각적 강조를 줄여 행동할 항목이 잘 보이도록 함. https://design-system.service.gov.uk/components/task-list/
- W3C Reflow 문서는 접근 차단(403)되어 출처 근거로 사용하지 않음. 화면 폭 검증은 자체 성공조건으로 설정.
- 적용: 기존 네 메뉴 유지, 대표 결정과 분석을 상단에, 후보는 별도 접힘 영역, KPI는 관리 점검 진입점으로 축소. 문장 폭/행간/대비/줄바꿈 개선. 한국어 시스템 글꼴 유지.
- 제외: 장식 이미지/차트 추가, 폰트 의존성, 전체 프레임워크 교체, 분석 이력 비교 신설, 수집기 변경, 인증 변경, 운영 배포.
